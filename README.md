# Knight's Last Leap

**Knight's Last Leap** is a small 2D platformer game project built with the Godot Engine.

This game is my first attempt at making a game with Godot, and while it is far from complete, I wanted to release it as an open source project so others can look at it, learn from it, experiment with it, or build on top of it.

## About the Game

In **Knight's Last Leap**, you play as a knight trying to survive a dangerous platforming world filled with monsters, hazards, falling risks, and coins to collect.

The idea is simple:

- Run and jump through the level
- Avoid monsters
- Avoid falling
- Collect coins
- Try to survive as long as possible

This project is still very early and should be considered a work in progress.

## Current Status

This game is not finished.

It currently exists as an early prototype / learning project. Some mechanics may be incomplete, buggy, or missing entirely. Level design, enemy behavior, UI, sounds, polish, and gameplay balance are still being worked on.

## Why I Released It

I created this project as a way to learn the Godot Engine and understand how 2D platformer games are built.

Since this is my first real attempt at making a game in Godot, the code and design may not be perfect. That is part of the learning process. I am sharing it publicly in case it helps someone else who is also learning game development.

## Built With
